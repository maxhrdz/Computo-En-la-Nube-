# Cloud Computing Coursework

Academic exercises in C#.

The repository includes a C# project file and a `Filosofos/` folder. Generated `bin/` and `obj/` directories are also currently tracked.

## Explore

- [Filosofos/](Filosofos/) — exercise source
- [Computo En La Nube Codigos.csproj](Computo%20En%20La%20Nube%20Codigos.csproj) — project configuration

To build, install a compatible .NET SDK and inspect the target framework in the project file.

~~~bash
dotnet build
~~~

This repository contains learning exercises, not a deployed cloud service.
